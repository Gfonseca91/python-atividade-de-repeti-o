# 🏆 Jornada de Aprendizado: Lógica de Programação e Introdução à Análise de Dados com Python

Este repositório/notebook é um registro prático de estudos cobrindo desde conceitos fundamentais de controle de fluxo em Python até os primeiros passos em análise de dados utilizando a biblioteca Pandas.

---

## 📋 Estrutura do Conteúdo

### 1. 🔄 Estruturas de Repetição (`while`)
*   **Controle com Limite Definido:** Exemplo prático de contador incremental dinâmico a partir do input do usuário.
*   **Sistemas de Segurança Básicos:** Implementação de controle de acesso com limite de tentativas de senha e bloqueio de segurança.
*   **Loops Infinitos (`while True`):** Estruturas com condições de parada (`break`) para criação de menus interativos.

### 2. 🗃️ Estruturas de Dados Básicas
*   **Listas (`list`):** Manipulação, adição de novos elementos com `.append()` e iterações com laços `for`.
*   **Dicionários (`dict`):** Conceito de chave e valor para simular cadastros simples de usuários e saldos.

### 3. 🐼 Introdução à Biblioteca Pandas
*   **Leitura de Arquivos:** Importação de arquivos CSV (`pd.read_csv`).
*   **Exploração Inicial:** 
    *   `display(dados)`: Visualização formatada da tabela.
    *   `info()`: Verificação de tipos de dados, quantidade de registros e valores nulos.
    *   `describe()`: Análise estatística descritiva (média, desvio padrão, mínimos, máximos e quartis).
